# First Two Weeks Plan for Deep Learning Fundamentals

## Overview

In the first two weeks, we will focus on building the mathematical foundations necessary for deep learning. The plan includes:

- **Linear Algebra Fundamentals**
- **Implementation of Basic Operations from Scratch**

We'll also dive into the principles of back propagation through key resources.

---

## Key Resources

### Back Propagation

- **Seminal Paper:**  
  "Learning representations by back-propagating errors" (1988)  
  *Note:* The original paper's font can be challenging to read, so supplementing it with modern resources is encouraged.

- **Additional Sources:**  
  Search for up-to-date materials that extensively cover back propagation.

### Primary Text

- **Paper:** [The Matrix Calculus You Need for Deep Learning](https://arxiv.org/abs/1802.01528)  
  *Authors: Terence Parr and Jeremy Howard*

### Video Resource

- **Video Explanation:** [Matrix Calculus Overview by Adam Dhalla](https://youtu.be/Ixl3nykKG9M?si=8Zt_KnLsk0AKI1P0)  
  This video covers the contents of the primary text in detail.

## First Project: Neural Network from Scratch

- **Objective:** Build a neural network entirely from scratch using pure Python.
- **Constraints:**  
  - No usage of high-level frameworks like PyTorch or TensorFlow.
  - Emphasis on understanding every component and the underlying math.
- **Outcome:** Gain hands-on experience with neural network fundamentals and back propagation.
